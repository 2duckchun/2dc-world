# 개인정보 처리방침

2DC Tech Blog(이하 "사이트")는 「개인정보 보호법」 및 관련 법령을 준수하며,
이용자의 개인정보 보호를 위해 다음과 같이 처리방침을 두고 있습니다.

본 처리방침은 사이트가 직접 수집·처리하는 정보를 다룹니다.

## 1. 수집하는 개인정보 항목 및 수집 방법

### 1-1. 자동 수집 항목

| 항목 | 설명 |
| --- | --- |
| IP 주소, 접속 로그 | 호스팅 인프라(Vercel) 차원에서 수집 |
| 쿠키, 기기·브라우저 정보, 페이지 이동 경로, 체류 시간 | Google Analytics 4 (Google Tag Manager를 통해 로드) |

### 1-2. 이용자가 제공하는 항목 (GitHub 로그인 시)

GitHub OAuth 인증 동의 시 GitHub로부터 다음 정보를 받아 저장합니다.

- GitHub 사용자 식별자(`github_id`), 사용자명(`github_username`)
- 표시 이름, 이메일 주소, 프로필 이미지 URL

### 1-3. 사이트 이용 과정에서 생성되는 항목

- 댓글 작성 시: 작성 내용, 작성 시각, 댓글 대상 글 식별자
- 좋아요 표시 시: 대상 글 식별자, 표시 시각
- 위 항목은 작성자(로그인한 사용자) 식별자와 연결되어 저장됩니다.

## 2. 개인정보의 처리 목적

- 회원 식별 및 인증
- 댓글·좋아요 등 사용자 인터랙션 기능 제공
- 사이트 이용 통계 분석 및 서비스 개선
- 부정 이용·악성 사용자 방지

## 3. 개인정보의 보유 및 이용 기간

| 정보 | 보관 기간 |
| --- | --- |
| 회원 계정 정보(GitHub OAuth) | 회원 탈퇴 또는 사이트가 서비스를 중단할 때까지 |
| 댓글·좋아요 기록 | 이용자가 직접 삭제하거나 회원 탈퇴 시 |
| Google Analytics 4 통계 데이터 | Google이 정한 기본 보관 기간(최대 14개월) 이후 자동 삭제 |
| Vercel 접속 로그 | Vercel이 정한 보관 기간에 따름 |

회원 탈퇴를 원하시는 경우 아래 "8. 개인정보 보호 책임자" 항목의 연락처로 요청해주시기 바랍니다.

## 4. 개인정보의 제3자 제공 및 처리 위탁

사이트는 다음 업체에 개인정보 처리를 위탁하고 있으며, 위탁받은 업체는 위탁 목적 외 용도로 정보를 사용할 수 없습니다.

| 수탁 업체 | 위탁 업무 | 위치 |
| --- | --- | --- |
| GitHub, Inc. | OAuth 로그인 인증 | 미국 |
| Vercel Inc. | 웹 호스팅 및 CDN | 미국 |
| Neon Inc. | 데이터베이스 호스팅 | 미국 |
| Google LLC | 트래픽 분석 (Google Analytics 4), 태그 관리 (Google Tag Manager) | 미국 |

상기 업체는 데이터센터가 미국에 위치하므로, 사이트 이용 시 일부 개인정보가 미국으로 이전되어 처리됨을 안내드립니다.

이용자는 Google Analytics에서 자신의 데이터 수집을 거부할 수 있습니다.

- Google Analytics 옵트아웃 도구: <https://tools.google.com/dlpage/gaoptout>

## 5. 정보주체의 권리

이용자는 언제든지 본인의 개인정보에 대해 다음 권리를 행사할 수 있습니다.

- 개인정보 열람 요구
- 오류 정정 및 삭제 요구
- 처리 정지 요구
- 회원 탈퇴(계정 및 작성 콘텐츠 삭제)

권리 행사는 본 처리방침 하단의 연락처로 요청해주시면 지체 없이 처리하겠습니다.

## 6. 쿠키의 사용

사이트는 다음 목적으로 쿠키를 사용합니다.

- 로그인 세션 유지
- 사용자 환경 설정(테마 등) 저장
- 트래픽 분석 (Google Analytics)

이용자는 브라우저 설정에서 쿠키 저장을 거부할 수 있으나, 일부 기능(로그인 등) 이용에 제한이 발생할 수 있습니다.

## 7. 개인정보의 안전성 확보 조치

- HTTPS 암호화 통신
- OAuth 기반 인증을 사용하여 비밀번호를 직접 저장하지 않음
- 관리자·일반 사용자 권한 분리
